# v96 — обложки и названия epub/fb2 + починенный ридер + категории + новости

## Что сделано (5 задач)

### 1. 🖼 Обложки книг epub/fb2 — теперь автоматом (build.py в books-репо)
Робот (`build.py`) раньше делал обложки только из PDF (первая страница). Теперь:
- **EPUB** — обложка извлекается из самого файла (стандартный cover-image / cover.xhtml → картинка);
- **FB2** — обложка извлекается из `<coverpage>` файла;
- приводится к тому же виду, что PDF-обложки (400×600, JPEG ~40–50 КБ);
- если в файле обложки нет — карточка показывает название (как раньше);
- идемпотентно: повторные запуски ничего не меняют.

Проверено на ваших книгах: «Армагеддон откладывается» (epub) ✓, «Армяне. Народ-созидатель» (fb2) ✓ — у «Архетип и символ» (fb2) обложки в самом файле просто нет.

### 2. 📖 Настоящие названия книг вместо транслита (build.py)
Файлы названы транслитом («1_Armaghieddon_otkladyvaietsia.epub»), а **внутри** каждого файла лежит настоящее название. Теперь manifest.json берёт его оттуда:

| Файл | Было в каталоге | Стало |
|---|---|---|
| 1_Armaghieddon_otkladyvaietsia.epub | 1 Armaghieddon otkladyvaietsia | **Армагеддон откладывается** |
| 1_Armianie._Narod-sozidatiel'.fb2 | 1 Armianie. Narod-sozidatiel' | **Армяне. Народ-созидатель** |
| 1_Arkhietip i simvol.fb2 | 1 Arkhietip i simvol | **Архетип и символ** |

Сами файлы НЕ переименовываются (все ссылки остаются рабочими) — меняется только отображаемое имя в каталоге, карточке и ридере. Работает для всех 446 новых книг автоматически.

### 3. 📕 Ридер: исправлены «не открывается / висит на 100% / только первая страница»
Диагностировано на ваших книгах, три причины — три исправления (reader.html + config.js):
- **«Только первая страница» (EPUB)** — открывалась обложка, а тап-зоны были скрыты, перелистывать было нечем. Теперь тап-зоны и свайп работают: тап слева/справа и свайп листают страницы EPUB.
- **«Висит на 100%»** — две причины: (а) кэш больших книг мог упасть по переполнению хранилища ПОСЛЕ загрузки — теперь кэш не может сломать открытие; (б) большие FB2 (2–10 МБ) рендерились одним куском и замораживали экран — теперь книга выводится порциями по 220 блоков с индикатором «Коркардри китоб...», экран не замирает.
- Библиотеки форматов (epub.js/mammoth) теперь грузятся **параллельно** со скачиванием книги (быстрее) + понятные статусы под процентом («Боркунии китоб...», «Омодасозии хонандаи EPUB...»).

### 4. 🏷 Кнопки категорий (kitobho.html) — обычные и статичные
- название категории больше НЕ бегущая строка — обычный статичный текст (до 2 строк, по центру);
- иконки/эмодзи из названий убраны;
- кнопки ниже: 72px → 46px, шире (56→74px), активная выделяется золотой рамкой без подпрыгивания.

### 5. 📰 Новости: фото показывается сразу + скрытое автообновление (index.html)
- **Предзагрузка фото**: первые 12 картинок новости грузятся заранее — при свайпе фото уже на месте (раньше дальние карточки начинали качать картинку только когда до них доскроллишь);
- **Скрытое автообновление**: каждые 5 минут приложение само проверяет news.json; если новости новые — лента перерисовывается без скелетона и без потери позиции. Обновлять страницу больше не нужно.

## Тесты (22/22 прошли)
