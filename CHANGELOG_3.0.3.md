# Китобхона 3.0.3 — офлайн и мубодилаи хабарҳо

## Офлайн
- Кэш Service Worker обновлён: все локальные страницы программы, JSON главной страницы, `offline-books.html`, PDF.js и нужные библиотеки читалки предварительно сохраняются.
- Новости и новости Президента показывают сохранённые данные даже после истечения короткого TTL; офлайн-лента новостей не исчезает, если сохранённые публикации старше суток.
- Добавлен экран «Китобҳои зеркашидашуда»: общий/индивидуальный размер, категории, поиск, открытие, отправка и удаление файлов из кэша.
- В настройках доступна автоочистка через 7, 10, 14, 20, 30 дней или 3 месяца; по умолчанию — без автоматического удаления.
- PDF.js и worker перенесены в локальные `assets/libs`, чтобы уже сохранённые PDF открывались без CDN и интернета.

## Новости Президента
- Исправлен текстовый шаринг; кнопка новости открывает выбор одной/нескольких фотографий (до 10) и предлагает отправить текст вместе с фотографиями.
- Кнопка «мубодила кардан» в полноэкранном просмотре фото продолжает отправлять текущую фотографию с подписью новости.
- Android 3.0.3 поддерживает ACTION_SEND_MULTIPLE с проверкой HTTPS-хостов prezident.tj/Flickr; браузер использует Web Share API, где он доступен, иначе предлагает безопасные ссылки.

## Проверка
- Все четыре проекта сохранены. Backend (`kitobkhona-chat`) и Edge API не менялись. Android APK/AAB следует пересобрать в GitHub Actions с действующими ключами подписи.
