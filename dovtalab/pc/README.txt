ЭТА ПАПКА — ДЛЯ ФАЙЛА Dovtalab-Setup.exe
=========================================

Положите сюда файл Dovtalab-Setup.exe (ваш установщик для Windows),
и программа на телефоне сможет скачать его ПРЯМО ИЗНУТРИ, без
браузера и без интернета.

Как загрузить в GitHub (до сборки APK):
1. Откройте репозиторий → вкладка Code → папка www → папка pc.
2. Add file → Upload files → перетащите Dovtalab-Setup.exe.
3. Commit changes.
4. Actions → Build APK, AAB and Windows EXE → Run workflow.

Если файла здесь нет — программа автоматически предложит скачать
версию с GitHub Releases (нужен интернет).
