# v97 — обложки всех книг + переименование в настоящие названия + скорость каталога + формат в карточке

## Что было и что сделано

### 1. 🖼 Почему у книг (кроме PDF) не было обложек — найден и исправлен баг
**Причина:** в каталоге (`kitobho.html`) адрес обложки строился заменой **только** `.pdf` → `.jpg`:
```js
file.replace(/\.pdf$/i, '.jpg')   // было — для epub/fb2 ничего не заменялось!
```
Для книги `1_Armaghieddon.epub` получался адрес обложки `.../1_Armaghieddon.epub` (с расширением книги!) → 404 → пустая карточка. Робот при этом клал обложку правильно (`.jpg`) — просто приложение смотрело не туда. (Вы правильно догадались, что дело в несовпадении имён — теперь адрес строится по имени файла для **всех** форматов: pdf/epub/fb2/doc/docx/mp4/txt.)

### 2. ✏️ Переименование книг в настоящие названия (build.py, books-репо)
Робот теперь **переименовывает сами файлы epub/fb2** в настоящее название изнутри файла — включая таджикские книги:

| Было (файл) | Стало (файл = название = обложка) |
|---|---|
| 1_Armaghieddon_otkladyvaietsia.epub | **Армагеддон откладывается.epub** + Армагеддон откладывается.jpg |
| 1_Armianie._Narod-sozidatiel'.fb2 | **Армяне. Народ-созидатель.fb2** + такая же обложка |
| 1_Shohnoma... | **Шоҳнома достони тоҷикӣ.fb2** (таджикские буквы ӣ/ҳ/ӯ/ҷ сохраняются) |

- имя файла = название в каталоге = имя обложки — всё совпадает;
- существующие обложки переименовываются вместе с книгой (не теряются);
- запрещённые в именах файлов символы (/:*?"<>|) убираются автоматически;
- коллизии одинаковых названий решаются суффиксом «(2)»;
- PDF не переименовываются (из PDF название надёжно извлечь нельзя — их имена и так нормальные);
- идемпотентно: повторные запуски ничего не меняют.

### 3. ⚡ Скорость каталога (главная причина тормозов)
Папка «Фарҳангшиносӣ» теперь содержит **701 книгу** — старый код рисовал все 701 карточку сразу → экран подвисал. Теперь:
- карточки рендерятся **порциями по 48**, следующие догружаются автоматически при прокрутке (надпись «⏳ Боркунии китобҳо...»);
- рейтинги и обложки обрабатываются только для новых карточек;
- загрузка страницы каталога: **~44–73 мс** (замерено на папке в 701 книгу).

### 4. 🏷 Формат книги в карточке + размер внизу
Там, где раньше было «12.3 МБ», теперь:
- **бейдж формата** — PDF / EPUB / FB2 / DOCX / MP4 / TXT (свой цвет у каждого формата: PDF — красноватый, EPUB — зелёный, FB2 — оранжевый, DOCX — синий, MP4 — фиолетовый);
- **размер файла в МБ** — маленькой строкой сразу под бейджем формата.

## Порядок установки
1. **Сначала** залить `build.py` в books-репо → робот запустится сам: переименует ~590 файлов epub/fb2, перенесёт/создаст обложки, пересоберёт манифесты и books.json. Это большой коммит и работа на несколько минут — не отменяйте.
2. Потом залить файлы из `kitobkhona_v97_patch.zip` в веб-репо.
3. На телефоне: открыть каталог → категория «Фарҳангшиносӣ» — книги с настоящими названиями, обложками, бейджами формата; прокрутка быстрая.

## ⚠️ Однократные последствия переименования (важно знать)
- «Продолжить чтение» и «Мои книги» у **переименованных** книг собьются один раз (адрес книги изменился) — их нужно открыть заново. PDF-книги и старые закладки на PDF не затронуты.
- Кэш каталога в приложении живёт 24 часа — чтобы увидеть новые названия сразу, переоткройте страницу каталога (или подождите сутки).
- Скачанные (офлайн) книги останутся в кэше под старыми адресами — при первом открытии книга скачается заново под новым именем.
