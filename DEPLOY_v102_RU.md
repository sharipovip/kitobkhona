# v102 — Новости Президента: САМЫЙ ВЕРХ + только НАСТОЯЩИЕ фото с prezident.tj

**Дата:** 29.09.2026 · **Тесты: 8/8 (вкл. фото-приоритет, ротацию 10 сек, enrichment
старой секции), 0 JS-ошибок**

Доработки поверх v101 (v101 должна быть уже установлена — president.js и
president.html не меняются).

---

## Что сделано

### 1. Раздел перенесён НА САМЫЙ ВЕРХ главной
Раздел президентских новостей теперь стоит **выше «🏆 Озмунҳои ҷумҳуриявӣ»** —
первое, что видно после шапки.

### 2. Новое название раздела
«🇹🇯 Хабарҳо аз сомонаи расмии Президенти ҶТ» — в две строки, компактно
(12.8px), чтобы занимало мало места.

### 3. ТОЛЬКО настоящие фото с сайта prezident.tj
Раньше некоторые президентские новости показывали наши собственные заглушки
(assets/newsimg). Теперь везде — **настоящие фотографии из самой новости**
(сервер фото сайта — flickr/live.staticflickr.com):

- **Новый раздел на главной**: ротация начинается с новостей, у которых есть
  настоящее фото; превью-фото 58px рядом с заголовком.
- **Старая секция «Ахбороти расмӣ»**: если робот ещё не успел положить фото в
  news.json, приложение само находит фото по номеру новости (id из ссылки
  prezident.tj/event/news/…) через открытый API сайта и подставляет его.
- **Сборщик news.json** (`tools/news_fetch.py`): теперь скачивает превью-фото
  каждой президентской новости (API event-flickr-images) — после первого же
  запуска робота фото приходят уже в самом news.json.
- **Надёжность**: фото подставляется только после того, как оно реально
  загрузилось (предзагрузка). Если flickr временно недоступен — карточка
  остаётся с прежней картинкой, пустых карточек не бывает.

## Изменённые файлы

| Файл | Что это |
|---|---|
| `index.html` | раздел выше Озмунҳо + новое название; фото-приоритет ротации; превью 58px; подстановка настоящих фото в старую секцию |
| `sw.js` | версия кэша → `kitobkhona-v102-president-top` |
| `tools/news_fetch.py` | сборщик news.json тянет настоящие фото новостей (flickr) |

**news.json в патч НЕ входит** — его обновит робот при первом же запуске
(ежечасно). Пока робот не сработал, приложение само находит фото через API —
пользователь видит настоящие фото сразу после установки патча.

## Установка

1. Распакуйте `kitobkhona_v102_patch.zip` поверх веб-репо
   (3 файла + эта инструкция).
2. Закоммитьте → GitHub Pages.
3. На телефоне полностью закройте и откройте приложение
   (кэш обновится сам через сервис-воркер).
