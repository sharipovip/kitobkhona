# Этап 1 — Reader и страница Алии (v5)

## Что изменено
- index.html: убрана карточка «АЛИЯ — Зеҳни сунъӣ» под цитатой президента (Алия остаётся в нижней навигации).
- reader.html: убрана кнопка ✨ у поиска в верхней панели; плавающая кнопка Алии поднята (bottom 108px) над нижней навигацией.
- aliya/reader-aliya.html: новая страница Алии:
  - 6 компактных кнопок: Хулосаи мавзӯъ, Калимаҳо ва истилоҳот, Тарҷума, Санҷиш ва тест, Нақшаи дарс, Сабт дар ёддошт.
  - Окно выбора только там, где нужно: диапазон страниц; тарҷума — язык (по умолчанию Русский); тест — намуд материала и число (вводится вручную). Калимаҳо запускаются сразу. Класс и язык для остальных — автоматически.
  - Статус «Ба хондан шурӯъ кардам… / Мехонам… / Тест месозам…» с иконкой ✨ в одну строку, ответ печатается по буквам.
  - Имена и термины (**…**) выделяются жёлтым.
  - Инструменты: Нусхабардорӣ, Word (.doc), PDF (печать), Ба ёддошт (сохраняется в браузере по книге).
  - Убрана надпись «Танҳо китобҳои матнии PDF».
