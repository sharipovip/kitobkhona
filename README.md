# 📚 Китобхона v3.0 — Manifest.json (без лимитов!)

## 🆕 Главное:

**Программа НЕ использует GitHub API** — читает только `manifest.json` из папки.

✅ Никаких лимитов  
✅ Очень быстро  
✅ Работает офлайн  

---

## 🏗 Как устроено:

```
GitHub repo: sharipovip/books/
├── sinfi_1/
│   ├── 📄 manifest.json    ← список книг (создаёт admin)
│   ├── 📄 book1.pdf
│   └── 📄 book2.pdf
├── sinfi_2/
│   ├── 📄 manifest.json
│   └── ...
```

**manifest.json** — это список книг в папке:
```json
{
  "version": 1,
  "books": [
    {"name": "Забони тоҷикӣ", "file": "Забони тоҷикӣ.pdf", "size": 2100000},
    {"name": "Математика", "file": "Математика.pdf", "size": 2800000}
  ]
}
```

---

## 🎯 Раванди корӣ:

### Шаг 1: Загрузи PDF в репо `sharipovip/books`
Создай папку (например `sinfi_2`) → закидай PDF файлы.

### Шаг 2: Открой admin
👉 https://sharipovip.github.io/kitobkhona/admin.html

### Шаг 3: Кликни «📝 Сохтани manifest»
- Выбери папку (например `sinfi_2`)
- Нажми «📝 Сохтани manifest»
- Программа сканирует, показывает список книг
- Нажми «⬇ Юклаб гирифтани manifest.json»

### Шаг 4: Залей manifest.json в папку
- Открой папку `sinfi_2` на GitHub
- Кликни «Add file» → «Upload files»
- Перетащи скачанный `manifest.json`
- **Commit changes**

### Шаг 5: Тамом! ✅
Программа в телефоне сразу видит новый бахш.

## 📦 Файлы в архиве:

```
📂 kitobkhona-full/
├── 📄 index.html      ← ЗАМЕНИТЬ
├── 📄 admin.html      ← ЗАМЕНИТЬ (новая кнопка «📝 Сохтани manifest»)
├── 📄 books.json      ← Уже актуальный (с `folder`)
├── 📄 manifest.json   ← PWA (не путать с manifest.json в папках книг!)
├── 📄 sw.js
├── 🖼️ icon-192.png
├── 🖼️ icon-512.png
└── 📂 android-app/    ← НЕ менять (он использует сайт)
```

---

## ⚠️ Важно:

- **Android приложение** не нужно пересобирать! Оно показывает сайт.
- **Каждая папка** в `sharipovip/books/` должна иметь `manifest.json`
- **Имена папок** в books.json должны совпадать с папками в GitHub
- **GitHub API** используется только в admin при генерации manifest (1 раз)
