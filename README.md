## ✨ Что нового в v1.2:

### 🌐 Offline-first (РЕШЕНИЕ ГЛАВНОЙ ПРОБЛЕМЫ!)
- **Service Worker** кэширует сайт целиком
- Без интернета сайт **открывается мгновенно** из кэша
- Книги, которые уже скачаны — доступны без интернета
- При появлении интернета — автоматическое обновление в фоне
- Баннер сверху показывает офлайн-статус

### ⚡ Скорость загрузки (быстрее!)
- books.json грузится из IndexedDB **мгновенно**
- Параллельная распаковка ZIP (по 4 файла)
- Lazy loading обложек (только видимые)
- HiDPI рендеринг PDF (чёткое отображение)

### 🎨 UI улучшен
- **Убрана кнопка** "Кэшро тоза кардан" (мешала)
- Баннер "📡 Офлайн" появляется только когда нет интернета
- Иконка стала красивее (стек из 3 книг)

### 📱 Android
- versionCode 3 → старая иконка обновится при установке
- PNG иконки в 5 разрешениях для совместимости
- Лучшая работа с Service Worker

## 🚀 ШАГ 1: Веб-сайт на GitHub Pages

В репозитории `kitobkhona`:
1. **Удалить** все старые файлы
2. **Загрузить новые** (из папки `kitobkhona-full`, БЕЗ `android-app/`):
   - `index.html`
   - `admin.html`
   - `books.json`
   - `manifest.json`
   - `sw.js` ← **ВАЖНО! Это новый файл**
   - `icon-192.png`
   - `icon-512.png`
3. Commit

После загрузки сайт работает offline после первого открытия!

---

## 📱 ШАГ 2: Android-приложение

В репозитории `kitobkhonaapp`:
1. **Удалить** все старые файлы
2. **Загрузить** содержимое `android-app/` (включая `.github`)
3. Commit
4. Actions → Wait → Скачать APK
5. **Установить ПОВЕРХ старого** — иконка обновится

---

## ⚠️ Главное про offline на телефоне:

После первого открытия с интернетом:
- Сайт **полностью кэшируется** через Service Worker
- При следующих запусках работает **без интернета**
- Если в книгах что-то новое (вы добавили) — обновится в фоне когда снова появится интернет

---

## 🛠 Управление книгами

Открой: https://sharipovip.github.io/kitobkhona/admin.html

1. **📂 Кушодан** → выбрать `books.json`
2. Добавить категории/бахшы/силкаҳои ZIP
3. **💾 Сабт** (Chrome) или **⬇ Юклаб**
4. Commit обновлённый `books.json` в GitHub
5. ✅ Пользователи получат обновление **автоматически** при следующем открытии (или сразу через pull-to-refresh)
