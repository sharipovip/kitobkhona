# 📚 Китобхона v3.1 — Авто обложки + Выбор папки

## 🆕 Что нового:

### 1️⃣ Обложки появляются АВТОМАТИЧЕСКИ ⚡
- При входе в бахш сначала видно названия книг (мгновенно)
- В фоне программа скачивает PDF (по 2 одновременно) и делает обложки
- Через несколько секунд все обложки появляются сами
- При повторном входе — обложки мгновенно из кеша

### 2️⃣ Клик по обложке = открыть книгу 📖
Раньше нужно было нажать «📖 Хондан». Теперь тапаешь по самой картинке книги.

### 3️⃣ Скачивание с выбором папки 📁
- **На компьютере** (Chrome/Edge) — открывается диалог «Куда сохранить?»
- **В Android приложении** — открывается системный диалог Android (выберешь любую папку: Downloads, Documents, SD-карта и т.д.)

## 🎯 Как создать manifest.json для папки:

1. Открой https://sharipovip.github.io/kitobkhona/admin.html
2. Кликни **«📝 Сохтани manifest»**
3. Выбери папку (например `sinfi_1`)
4. Нажми **«📝 Сохтани manifest»**
5. Нажми **«⬇ Юклаб гирифтани manifest.json»**
6. Залей `manifest.json` в папку `sinfi_1/` на GitHub → Commit

## ⚡ Как работают обложки:

```
Открыл бахш →
  ⚡ МГНОВЕННО показывает плитки с названиями
  📥 В фоне грузит PDF (по 2 параллельно)
  🖼️ Делает обложку из первой страницы
  💾 Сохраняет в кеш телефона (IndexedDB)
  ✨ Показывает обложку
  
Открыл этот же бахш повторно →
  ⚡ МГНОВЕННО все обложки из кеша
  
Нажал на обложку →
  ⚡ Книга открывается мгновенно (PDF уже в кеше)
```
