## Дополнительно (вторая просьба)
| Файл | Что сделано |
|---|---|
| `config.js` | **Обновление/очистка кэша из админ-панели больше не зависает на 92%.** Раньше шаги (`caches`, `serviceWorker.update()`) не ограничивались по времени, а при ошибке окно не закрывалось вовсе. Теперь каждый шаг ограничен, прогресс идёт по реальным этапам (25 → 65 → 90 → 100%), окно всегда закрывается (в худшем случае ≈15 с), затем страница перезагружается один раз |
| `index.html` | **Цитата Президента и фото снова меняются одновременно.** Раньше текст менялся сразу, а фото подгружалось из сети позже. Теперь фото сначала полностью загружается и декодируется, затем фото, текст и фон меняются в одном кадре; следующее фото грузится заранее; если фото не загрузилось, показывается следующая цитата, а не чужое фото |

## Проверено (Playwright, 390 px и 1440 px)
- Ни на одной странице нет JS-ошибок и горизонтальной прокрутки.
- «Хулосаи мавзӯъ» на реальной книге («Чаҳор мақола», сканированная) — ответ получен, имена выделены.
- «Калимаҳо» в ридере → 🔖 → запись появилась в панели «Ёддоштҳо» ридера.
- Чат: ответ шлюза, статус в одну строку, кнопки Нусха / Word / PDF / 🔖 в один ряд.
- «+»: фото распознано через vision, .txt прочитан.
- Обновление из админки при «зависающих» `caches` и `serviceWorker`: окно дошло до 100% и закрылось, повторного запуска нет.
- Цитаты при задержке загрузки фото 2,5 с: 0 расхождений текста и фото за 18 секунд наблюдения.
