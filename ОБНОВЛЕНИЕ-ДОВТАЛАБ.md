## КУДА СТАВИТЬ ФАЙЛ Dovtalab-Setup.exe

Положите его сюда (папка уже создана и ждёт файл):

    kitobkhona/dovtalab/pc/Dovtalab-Setup.exe

Имя файла должно быть точно: `Dovtalab-Setup.exe`

Как это работает:
- Если файл лежит в `dovtalab/pc/` — кнопка скачивания отдаёт его прямо с сайта
  (работает даже без интернета, «нусхаи дохилӣ»).
- Если файла там нет — кнопка автоматически качает с GitHub Releases:
  https://github.com/sharipovip/Dovtalab/releases/download/latest/Dovtalab-Setup.exe

Важно: GitHub Pages принимает файлы до 100 МБ.
Если Dovtalab-Setup.exe больше 100 МБ — НЕ кладите его в папку pc/,
а загрузите в GitHub Releases репозитория sharipovip/Dovtalab
(релиз с тегом `latest`, имя файла — `Dovtalab-Setup.exe`) — кнопка сама его подхватит.
