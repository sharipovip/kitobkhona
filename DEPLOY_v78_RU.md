**Про телефон (Kotlin/WebView-сборка):** веб-страница сама по себе не может сохранить файл в память телефона — Android WebView игнорирует атрибут `download`. Чтобы скачивание заработало, добавьте в Kotlin-код приложения обработчик (10 строк, копировать в `onCreate` рядом с настройкой webView):

```kotlin
webView.setDownloadListener { url, userAgent, contentDisposition, mimeType, _ ->
    try {
        val request = android.app.DownloadManager.Request(android.net.Uri.parse(url))
        request.setMimeType(mimeType)
        val cookies = android.webkit.CookieManager.getInstance().getCookie(url)
        if (cookies != null) request.addRequestHeader("cookie", cookies)
        request.addRequestHeader("User-Agent", userAgent)
        request.setNotificationVisibility(android.app.DownloadManager.Request.VISIBILITY_VISIBLE_NOTIFY_COMPLETED)
        val name = android.webkit.URLUtil.guessFileName(url, contentDisposition, mimeType)
        request.setDestinationInExternalPublicDir(android.os.Environment.DIRECTORY_DOWNLOADS, name)
        val dm = getSystemService(android.content.Context.DOWNLOAD_SERVICE) as android.app.DownloadManager
        dm.enqueue(request)
    } catch (e: Exception) {
        android.widget.Toast.makeText(this, "Боргирӣ имконпазир нест", android.widget.Toast.LENGTH_SHORT).show()
    }
}
```
После этого нажатие «Боргирӣ…» сохраняет файл в «Загрузки» с уведомлением. В обычном браузере скачивание работает и так.
