КИТОБХОНА — ЕДИНЫЙ АРХИВ ИНТЕГРАЦИОННЫХ ОБНОВЛЕНИЙ
Версия клиентского кода: 3.2.0. Дата: 21.11.2026.

ВАЖНО О СТАТУСЕ
В этом архиве собраны текущие изменения интеграции в исходный клиентский проект. Это не HTML-макеты с фиктивными ответами. Оригинальные API, формы и бизнес-правила сохранены. Оформление адаптировано к исходной структуре страниц; это не механическая замена страниц содержимым макетов и не гарантия попиксельного совпадения всех экранов.
Проверки на локальном стенде проведены. Реальные серверные аккаунты, доставка писем/push, реальные модели ИИ, экспорт через внешний сервис и работа production-базы НЕ проверялись. Поэтому сборку нельзя считать подтверждённым безошибочным production-релизом. Сначала установите на тестовую копию сайта.

КАК УСТАНОВИТЬ — ОДИН АРХИВ, БЕЗ ПРЕДЫДУЩИХ ЧАСТЕЙ
1. Сделайте обычную копию папки действующего проекта на своём компьютере.
2. Распакуйте ЭТОТ архив в папку тестовой копии проекта, где находятся index.html и config.js. Согласитесь на замену файлов. Папки aliya и assets должны объединиться с существующими, а не заменить их целиком.
3. Остальные файлы исходного проекта НЕ удаляйте. Это архив обновлений, не самостоятельный полный сайт. Предыдущие CHECKPOINT и rollback архивы применять не нужно.
4. Папка _UPDATE_INFO содержит только инструкцию, план, контрольные суммы и результаты проверок. Её можно не публиковать на сайте.
5. Откройте тестовый сайт по HTTP/HTTPS. Не открывайте index.html двойным щелчком как file://: PDF, Service Worker и API могут не работать.
6. После загрузки новой версии обновите страницу ещё раз. Версия Service Worker повышена до v162; старые оболочки могут оставаться до активации нового worker. Не очищайте данные реального аккаунта ради обновления. Сохранённый PDF-кэш не переименован и не удалён патчем.
7. Проверьте вход, книгу, сохранение прогресса, Алия, экспорт, ленту/чат и push на тестовом аккаунте. Удаление аккаунта проверяйте ТОЛЬКО на специально созданном тестовом аккаунте.
8. Если тестовый стенд работает корректно, перенесите те же файлы на основной сайт. Откат: вернуть файлы из своей резервной копии. Отдельный архив отката не требуется.

ЧТО ВНЕДРЕНО В ИСХОДНЫЙ КОД
- Единый слой оформления для главной, каталога, сохранённых книг, профиля, ленты, чатов, диалога, рейтинга и авторизации через config.js. Эти страницы продолжают пользоваться исходными функциями и данными, даже если сам их HTML не вошёл в архив, поскольку не изменился.
- Только три общие темы: Шаб / Рӯз / Минимализм. Переключатели профиля и отдельной Алии синхронизированы с сохранённой темой.
- Главная: компактный hero 116px, раздельные фото/цитата, оригинальные государственные символы и их окна; меню со ссылками и тремя темами; три равных быстрых перехода; поиск с согласованной строкой; прокрутка обложек; автоматическое пролистывание одного конкурса локально, без запроса к базе; ссылка «Ҳамаашро дидан».
- Список конкурсов: шесть круглых эмблем, поиск, статусы и дни, исходные подробные окна. Актуальный статический JSON читается один раз при открытии; при недоступности есть встроенный резервный набор. Перенесённые исходным алгоритмом даты отмечаются «тахминӣ». Отдельные страницы конкурсов не изменялись.
- Каталог: тематические иконки, исходная нумерация классов, согласованный placeholder, реальные действия книги в центрированном native dialog. Используются те же исходные кнопки/обработчики; при закрытии панель возвращается в исходный DOM.
- Reader: WebGL-изгиб настоящего PDF-холста под управлением жеста; отмена с возвращением, перелистывание назад/вперёд; fallback исходного рендера при отсутствии WebGL/медленной подготовке. Pinch/не-PDF режимы сохраняются. Центр скрывает панели, края перелистывают; автоскрытие после 15 секунд; яркость и бумажные настройки исходные. Десятибалльная исходная шкала не менялась: все десять звёзд одинаковые, в двух строках, чтобы не уменьшать их до нечитаемого размера.
- Профиль: оригинальные редактирование, статистика, 18+, права аватара, все 18 тем справки и её поиск, описание, поддержка, политика, условия, выход и два подтверждения удаления сохранены. Демонстрационных заглушек из макета нет.
- Лента: исправлен ошибочный исходный селектор перехода из имени/аватара к профилю; добавлен полупрозрачный книжный фон по реальному названию публикации без сторонней загрузки.
- Диалог: снята рамка/свечение со всей формы ввода и её контейнеров, а не только с textarea. Обработчики отправки исходные.
- Алия: компактная история, корректное меню вместо логотипа; реальные инструменты, остановка, исходные действия Нусха / Word / PDF / заметки сохранены.
- Алия в Reader: согласованное оформление поверх исходного AT.run/loadPdf; звезда не перекрывает заголовок, локальная анимация с ускорением/замедлением и reduced-motion.
- Вход, регистрация, гость, восстановление пароля: исходный код submitAuthForm / guest / checkReset / doReset не заменён макетными обработчиками. Изменения оформления приходят из общего слоя.

ЭКОНОМИЯ NEON
- Удалён повторный опрос дружбы каждые 30 секунд. Первичная загрузка, действия и возврат на страницу остаются.
- Удалён 15-минутный опрос уведомлений. Существующие push, открытие уведомлений и обновление по возврату не отключены.
- Проверка cache-control при загрузке теперь учитывает видимость и online, а 30-минутный TTL делится вкладками через localStorage. Повторного таймера не добавлено.
- Локальные checkpoints чтения, очередь синхронизации, отложенные запросы и backoff оставлены: их удаление могло потерять прогресс.
- Перелистывание конкурсов, часы, анимации, пересчёт статусов не являются сетевым polling. news.json / books.json — статические ресурсы, не доказательство SQL-запросов.
- Новый approved-ui.js не содержит fetch/XMLHttpRequest и не создаёт API-поллинга.
- Сон Neon НЕ гарантирован клиентским патчем: серверные cron, health-check, пулы соединений, другие клиенты и autosuspend из этого проекта не доступны для проверки. GPU ИИ и compute-часы Neon — разные расходы.

НЕ ПРОВЕРЕНО НА РЕАЛЬНОМ СЕРВЕРЕ
Настоящий вход/регистрация/восстановление, письма, push, создание/удаление аккаунта, доставка сообщений, запись рейтинга, выгрузка документов внешним сервисом, OCR/модель, Android native bridge, обновление Service Worker у действующего пользователя, полноценная offline-сессия после перезапуска и реальные метрики сна Neon. Серверные адреса и контракты сохранены, но это не равно подтверждению доступности backend.

Для архива использованы только отличающиеся от снимка файлы. Внутри нет тестовых токенов, PDF-фикстур или демо-аккаунтов. Серверные секреты не добавлялись. На действующий сервер из этой сессии ничего не выкладывалось.
