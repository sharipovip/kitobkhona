# КИТОБХОНА — версия 79 (скачивание как у книг + новости со всех сайтов)

## Что исправлено в v79

### 1. Скачивание парчам / нишон / суруд — ПО СХЕМЕ КНИГ ✅
Проблема: в Kotlin-сборке (WebView) кнопки скачивания не работали — WebView игнорирует обычные ссылки `download`.

Решение: скачивание теперь идёт **точно по схеме, которой скачиваются книги** (`downloadFile` из config.js):

```
fetch(файл) → blob → AndroidBridge.saveFile(base64, имя, тип)   ← телефон (ваш Kotlin-мост)
                ↓ если моста нет
             navigator.share (поделиться файлом)
                ↓ если недоступно
             blob-ссылка + a.download                             ← обычный браузер
```

Имена файлов правильные: `Парчами_давлатии_Тоҷикистон.png`, `Нишони_давлатии_Тоҷикистон.jpg`, `Суруди_Миллии_Тоҷикистон.mp3`. Кнопки: «⬇ Боргирӣи акси парчам», «⬇ Боргирӣи акси нишон», «⬇ Боргирӣи суруди миллӣ».

**Ничего менять в Kotlin-коде не нужно** — используется тот же `AndroidBridge.saveFile`, что уже работает у книг. Протестировано с имитацией моста: файл (PNG 64 КБ и MP3 1,8 МБ) передаётся в мост корректно.

### 2. Новости — все сайты раздела «Сомонаҳои давлатӣ»
Сборщик опрашивает **8 официальных источников** (все сайты раздела, кроме mmk.tj, который не открывается во встроенном браузере): Президент (API), Ховар, МЗС, Маориф, НТЦ, КМТ (Китобхонаи милли), Душанбе, Хатлон. Источники чередуются по кругу. В ленте отображается источник у каждой новости.

### 3. Новости без фото — текст по всей карточке
Если у новости нет фотографии, её **полный текст размещается по всей карточке** (сверху донизу, заголовок поверх затемнения снизу). Карточка не пустая.

### 4. Случайный порядок при каждом обновлении
При каждом обновлении главной страницы карусель новостей **начинается со случайной новости** (не всегда с первой). Проверено: при трёх обновлениях стартовые карточки — 0, 16, 6.

### 5. Фото новостей — как обложки книг
Фото грузится **прямиком с оригинального сайта** (как обложки книг — напрямую), а не через сервис сжатия. Если прямая загрузка не удалась — автоматически пробуется сжатая копия (`images.weserv.nl`), затем значок 📰. Если картинка «зависла» — через 12 секунд автоматически включается запасной вариант. Текст новостей никогда не ждёт картинок.

### 6. Активная карточка отцентрирована
Карточка (в т.ч. случайная стартовая) стоит ровно по центру экрана, соседние видны с обоих краёв.
