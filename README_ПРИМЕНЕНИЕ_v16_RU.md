# Применение обновления v16

Распакуйте обновление поверх веб-репозитория, сохранив структуру каталогов. Пакет содержит текущие изменения главной страницы, Алии, Service Worker и проверки.

Новые desktop stylesheets включаются только на экранах от 1200 px с мышью/трекпадом; телефонный layout не перестраивается этими файлами. Кнопка уведомлений закреплена для мобильной шапки отдельно. Для обновления PWA используется cache `kitobkhona-v155-desktop-aliya-redesign`; если браузер продолжает показывать старый интерфейс, перезагрузите сайт после обновления Service Worker.

Алия: вместо отдельного гамбургера нажмите фирменный знак Алии, чтобы открыть список чатов; «+» создаёт новый диалог. Голосовой режим и настройки голоса удалены, режим reasoning задаётся `high` постоянно.

Проверки: `python tests/check_aliya_html.py` и `node tests/aliya-smoke.js`. Браузерный E2E и реальный телефон/APK необходимо дополнительно проверить после публикации.
