# Kitobkhona v46 — исправления главной страницы и чистка

Архив содержит полный фронтенд с исправлениями v46. Публикация — как обычно: скопировать содержимое папки `kitobkhona/` в репозиторий GitHub Pages и сделать push.

## Что исправлено

### 1. Китобҳои Пешвои миллат не показывались после обновлений

Причина: старый кэш в localStorage устройств читался без проверки срока годности:

- `kk_booksjson_cache` — старый books.json (без категории «Пешвои Миллат») оставался навсегда;
- `kk_manifest_cache` — при одном сбое сети пустой массив `[]` кэшировался навсегда;
- `kk_home_search_index_v1` — старый поисковый индекс без книг Президента жил вечно.

Исправления в `index.html`:

- `loadBooksJson()` — кэш живёт 30 минут (`kk_booksjson_ts`), старый кэш без метки времени считается просроченным; при отсутствии сети старый кэш всё равно используется как резерв;
- `loadManifest()` — полный кэш живёт 24 часа, пустой — только 5 минут (`kk_manifest_ts`), затем повторная загрузка;
- `getHomeSearchIndex()` — кэш живёт 24 часа;
- `loadHome()` — если категории нет в books.json или manifest пуст, книги Пешвои миллат берутся из поискового индекса (страховочный путь). Карточки используют тот же стиль `.book-card-v3`, что и раздел «Китобҳои серхонтарин».

Проверено симуляцией «больного» кэша: до исправления — секция скрыта (0 карточек), после — 12 карточек.

### 2. Круглое фото при запуске (splash)

`splash_logo.jpg` имел белый фон с неровными полями — в круге была видна белая полоса.

- Создан `splash_logo.png` (340×340, прозрачный фон, эмблема выровнена по центру, белое убрано с корректной полупрозрачностью краёв);
- `index.html` использует `splash_logo.png`;
- `sw.js` кэширует оба файла.

### 3. Сомонаҳои давлатӣ — скриншоты вместо иконок + движение

- В превью-карточек теперь настоящие скриншоты главных страниц сайтов (`assets/sites/*.jpg`, 9 шт., сняты в сентябре 2026);
- Иконки-эмодзи убраны (остались только как запасной вариант, если картинка не загрузилась);
- Лента медленно движется справа налево (70 секунд на полный круг), все 9 сомон видны по очереди;
- При касании/наведении движение останавливается, после отпускания — продолжается;
- Края ленты плавно затухают (маска), подпись домена — поверх скриншота;
- Пользователям с включённой настройкой «уменьшить движение» показывается обычная прокрутка.

### 4. Чистка мусора

Удалены файлы, которые программа не читает:

- `chat #старый.html` — старая копия чата с битым именем;
- папка `hero/` (10 картинок) — не использовалась;
- `assets/hero/*-200.jpg` (10 маленьких копий) — не использовались;
- `assets/hero/04…10-*.jpg` (7 картинок старого дизайна hero) — не использовались;
- `assets/hero/hero_manifest.json` — не читается кодом;
- `icons/quotes-data.js` — дубликат корневого файла.

Из `index.html` удалено ~17 КБ мёртвого CSS (96 неиспользуемых классов старых версий: `.president-*`, `.hero-v4`, `.winner-*`, `.category-*` и др.) и 3 осиротевших @keyframes. Проверено попиксельным сравнением вычисленных стилей всех живых элементов до/после — визуально ничего не изменилось, кроме намеренных правок раздела сомон.

Оставлены (используются или могут понадобиться): `book_reviews.html`, `html_studio_full.html` (инструмент редактора), `firebase-messaging-sw.js` (требование Firebase).
