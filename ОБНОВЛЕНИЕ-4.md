# ОБНОВЛЕНИЕ 4 — все скачивания Довталаб «как книги из Китобхона»

Ставится поверх обновлений 1–3. Скопируйте файлы в корень kitobkhona с заменой.

## Суть

Сделан ЕДИНЫЙ модуль скачивания `dovtalab/assets/js/dl.js` — точно тот же канал,
что у книг в читалке Китобхона (`downloadCurrent()` → `downloadFile()`):

    скачивание с прогрессом «Ҳифз шуда истодааст... N%»
      → AndroidBridge.saveFile (мост приложения Китобхона)
      → Android показывает ДИАЛОГ ВЫБОРА ПАПКИ (ACTION_CREATE_DOCUMENT)
      → пользователь сохраняет файл куда хочет → «✓ Файл барои захира кардан омода»

## Что теперь скачивается через этот канал

1. Тесты PDF/Word («Намунаи тест» → Зеркашӣ, и «Мавод» → «Интихоб ва зеркашӣ»)
2. Dovtalab-Setup.exe (страница «Барои Windows») — с прогрессом:
   сначала dovtalab/pc/Dovtalab-Setup.exe (без интернета и без браузера),
   иначе GitHub Releases
3. Любые прямые ссылки на файлы (.pdf/.docx/.zip/.exe/...) внутри Довталаб

На компьютере/обычном браузере — как раньше, через «Загрузки».
В отдельном приложении Dovtalab (Capacitor/pywebview) — как раньше,
в «Документҳо/Довталаб».

## Состав архива
- dovtalab/assets/js/dl.js — НОВЫЙ единый модуль скачивания
- dovtalab/assets/js/export.js — экспорт тестов через DovDL
- dovtalab/assets/js/cap-downloads.js — прямые ссылки через канал reader
- dovtalab/Download-Довталаб.html — exe через DovDL (прогресс + выбор папки)
- dovtalab/pages/test-view.html — подключён dl.js
- dovtalab/pages/materials.html — подключён dl.js
- dovtalab/sw.js — dl.js в кэше (версия v16)
- sw.js — dl.js в кэше Китобхона (версия v134)
