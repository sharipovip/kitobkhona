# Kitobkhona v47 — исправление «первый раз видно, потом пропадает»

Архив содержит полный фронтенд с исправлениями v47 (поверх v46). Публикация: скопировать содержимое папки `kitobkhona/` в репозиторий GitHub Pages и сделать push.

## Главное исправление: Китобҳои Пешвои миллат

### Симптом
При первом входе раздел показывался нормально, при следующих — оставался только заголовок («Китобҳои Пешвои миллат», «Ҳамаашро бинед»), а карточки с рамкой и обложками пропадали.

### Причина (найдена воспроизведением)
В `index.html` два `<script>`-блока:

- блок 1 — здесь `loadHome()` и вызов `loadHome()` сразу в конце блока;
- блок 2 (ниже по документу) — здесь лежали функции `normalizeBookKey`, `isMyBook`, `syncMyBookButtons` («Китобҳои ман»), которые использует `pinButton()` при отрисовке карточек.

Когда сеть медленная (первый вход), `await fetch` в `loadHome` успевает уступить управление парсеру — блок 2 выполняется, функции определены, всё работает. Когда данные берутся из кэша мгновенно (второй вход), отрисовка карточек стартует сразу после блока 1, ещё до выполнения блока 2 → `ReferenceError: normalizeBookKey is not defined` → секция уже открыта (`display:block`), но карточки не создаются. Эту же ошибку ловили на устройствах и раньше (v45), когда кэш отдавался мгновенно.

### Исправление
Функции `MY_BOOKS_KEY`, `normalizeBookKey`, `matchesBook`, `getMyBooks`, `saveMyBooks`, `isMyBook`, `syncMyBookButtons` перенесены в первый блок — теперь они гарантированно определены до любого вызова `loadHome()`, независимо от скорости кэша и сети.

Проверено автотестом из 5 сценариев: первый вход, второй вход, третий, офлайн-перезапуск, перезапуск через 31 минуту — во всех случаях 12 карточек, ошибок нет. До исправления второй вход давал 0 карточек с ошибкой `normalizeBookKey is not defined`.

## Китобҳои нав — раздел удалён

Раздел «Китобҳои нав» удалён полностью (HTML, функция `loadNewBooks`, её вызов и мёртвое CSS-правило `#newSection .book-tag-v3`): он показывался при первом входе и пропадал при следующих (та же причина — случайный набор книг из манифестов). Остальные разделы («Китобҳои ман», «Китобҳои серхонтарин», «Сомонаҳои давлатӣ») не затронуты.
