# Kitobkhona v48 — свайп сомонҳо, сплэш и Service Worker

Архив содержит полный фронтенд с исправлениями v48 (поверх v46–v47). Публикация: скопировать содержимое папки `kitobkhona/` в репозиторий GitHub Pages и сделать push.

## 1. Сомонаҳои давлатӣ — свайп пальцем + анимация

Лента сайтов теперь управляется и пальцем, и анимацией одновременно:

- **Авто-движение** — медленно справа налево (22 px/с), все 9 сомон видны по очереди;
- **Свайп пальцем в обе стороны** — лента следует за пальцем: влево = смотреть дальше, вправо = вернуться;
- прокрутка **бесконечная в обе стороны** (два одинаковых набора карточек с бесшовным переходом);
- короткий **тап = открытие сайта** (кашолание тапом не считается — случайное открытие при перетаскивании исключено);
- после отпускания пальца авто-движение **возобновляется через 2.2 секунды** с нового места;
- `touch-action: pan-y` — вертикальная прокрутка страницы при касании ленты работает как обычно;
- пользователям с «уменьшенным движением» авто-прокрутка отключена, свайп работает.

Проверено автотестами: авто 22 px/с; свайп на 150 px двигает ровно на 150 px в обе стороны; после 3 свайпов за «нулевую» точку позиция корректно заворачивается (бесшовность); тап открывает мини-браузер; ошибок JS нет.

## 2. «Китобҳои нав» больше не появится даже один раз

Раздел удалён из HTML ещё в v47. Причина, по которой он мог мелькать **один раз при первом запуске** после публикации: старый Service Worker отдавал из кэша **старую версию index.html** (стратегия «кэш-первый» для страниц), и только после активации нового SW пользователь видел новую страницу.

Исправлено в `sw.js`: для запросов навигации теперь стратегия **«сеть-первая»** — браузер всегда пытается взять свежую страницу с сервера, и только при отсутствии интернета fallback на кэш/`offline.html`. После публикации v48 пользователи сразу видят новую версию, без одноразового показа старой.

## 3. splash_logo.png — большой, как раньше

В v47 эмблема занимала лишь 86% кадра (виднелось белое кольцо, логотип казался мелким). Переделано:

- эмблема занимает **98% кадра** (поля всего 5–8 px на 512 — на экране это ~2 px);
- 512×512, PNG без потери качества, 393 КБ;
- в круглом сплэше логотип крупный, как в самой первой версии, белого почти не видно (в зоне круга белый — 5.6%, было 22%).

Проверено пиксельным замером скриншота сплэша.
