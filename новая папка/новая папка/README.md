# 📚 КИТОБХОНА

## Маълумот дар бораи барнома

**Китобхона** — китобхонаи электронии тоҷикӣ, ки барои хонандагон, омӯзгорон ва ҳамаи дӯстдорони китоб тарҳрезӣ шудааст.

Ин барнома имкон медиҳад, ки китобҳои дарсӣ, адабиёти бадеӣ, шеърҳо, китобҳои таърихӣ ва дигар маводи фарҳангиро дар як ҷой пайдо кунед ва бихонед.

---

## ⭐ Имкониятҳои асосӣ

- 📖 **Хондани китобҳои PDF** бевосита дар барнома
- 🔖 **Хатчуб гузоштан** — сафҳаҳои дилхоҳро нишона занед
- ❤️ **Дӯстдоштаҳо** — китобҳои дилхоҳатонро ҷамъ кунед
- 🔍 **Ҷустуҷӯ дар саҳифа ва тамоми китоб**
- 🔊 **Хондани садо (TTS)** — гӯш кардани китоб
- 🌙 **3 намуди намоиш** — Торик, Равшан, Сепия
- 📵 **Кор кардан бе интернет** (китобҳои захирашуда)
- 📱 **Насб ҳамчун барнома** (PWA / APK)
- 📊 **Пайгирии прогресс** — хондани шумо нигоҳ дошта мешавад
- 🆕 **Нишондиҳии китобҳои нав** (NEW)
