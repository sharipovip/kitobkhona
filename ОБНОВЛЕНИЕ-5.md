# ОБНОВЛЕНИЕ 5 — открытие проводника телефона (выбор папки)

Ставится поверх обновлений 1–4. Скопируйте файлы в корень kitobkhona с заменой.

## Причина проблемы

На страницах Довталаб НЕ БЫЛО заглушки Android-моста. В Китобхона она есть в
config.js, на страницах «Маълумоти муфассал» — в maorif-details-tools.js, а в
Довталаб её не хватало. Поэтому вызов saveFile не доходил до приложения:
показывалось «файл зеркашишуд», но проводник (выбор папки) не открывался.

## Что исправлено

- dl.js теперь САМ создаёт AndroidBridge из нативного канала KitobkhonaNative
  (точная копия заглушки из config.js) + поддержка старого моста KitobAndroid.
- Теперь после скачивания ЛЮБОГО файла из Довталаб (тесты PDF/Word,
  Dovtalab-Setup.exe, прямые ссылки) Android открывает СИСТЕМНЫЙ ПРОВОДНИК:
  пользователь выбирает папку, имя файла и сохраняет.
- Сообщения согласованы: «Ҳифз шуда истодааст... N%» →
  «Ҷойи нигоҳдориро интихоб кунед…» (проводник) → «✓ Файл барои захира кардан омода».
