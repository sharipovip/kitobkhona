# Kitobkhona v49 — мини-патч: splash_logo без белой каймы

В архиве ТОЛЬКО изменённые файлы (замена поверх любой версии v46–v48):

```
kitobkhona/splash_logo.png   — логотип: эмблема вплотную заполняет весь кадр,
                               белой каймы вокруг круга больше нет (на экране <0.1%)
kitobkhona/sw.js             — CACHE_NAME → 'kitobkhona-v69-splash-edge'
                               (обязателен: без смены версии клиенты продолжали бы
                               показывать старую картинку из кэша Service Worker)
```

## Что изменилось

- Эмблема растянута на весь кадр 512×512 с запасом ~1% за края: круг маски сплэша
  теперь заполнен эмблемой до самой кромки — измерение на готовом экране показало
  0.05% белого в кольце у края (было сплошное кольцо 5–8 px).
- Искажение пропорций 1.2% — на глаз незаметно.
- `splash_logo.jpg` (оригинал) не тронут — он остаётся в проекте как резерв.

## Публикация

1. Заменить эти два файла в репозитории GitHub Pages.
2. `git add splash_logo.png sw.js && git commit -m "v69: splash без белой каймы" && git push`.

Пользователи увидят новый логотип после того, как Service Worker обновится
(обычно при втором открытии приложения после публикации).
