# Китобхона — Отчет об обновлениях и исправлениях (Версия 3.1.4 / v130)

Данный релиз содержит исправление ошибки сборки Android в GitHub Actions, визуальные доработки ленты и конкурсов, а также полноценную интеграцию Soro LLM (zehn).

---

## 1. Исправление ошибки сборки в GitHub Actions (`MainActivity.kt`)
* **Причина сбоя**: Шаг CI `Check R8 output` (скрипт `scripts/check_release.py`) проверял наличие в скомпилированном байткоде DEX и исходном коде нативного таргета WhatsApp (`b"whatsapp://send"`, `b"shareTextWithWhatsAppChooser"`, `appendQueryParameter("text", text)`, `Intent.EXTRA_INITIAL_INTENTS`, `ClipData.newPlainText(safeTitle, text)`). В предыдущей версии адрес `whatsapp://send` находился только в комментарии, из-за чего он удалялся компилятором и R8 выбрасывал ошибку:
  `FAIL: secure WebView bridge and native Sharesheet WhatsApp target retained in DEX`.
* **Решение**: Метод `requestShareTextWithWhatsAppChooser` в `MainActivity.kt` обновлен с созданием прямого интента WhatsApp через `Uri.parse("whatsapp://send").buildUpon().appendQueryParameter("text", text).build()` и добавлением его в `Intent.EXTRA_INITIAL_INTENTS` системного диалога `Intent.createChooser` с `ClipData.newPlainText(safeTitle, text)`.
* **Результат**: Все 15 проверок `check_release.py` проходят успешно, сборка release AAB и APK в GitHub Actions завершается без ошибок.

## 2. Обложка книги в Ленте (`Lenta.html`)
* **Проблема**: Ранее обложка книги размещалась ровно по центру экрана (`top: 50%; left: 50%; transform: translate(-50%, -50%)`), из-за чего блок с цитатой/текстом пользователя перекрывал её.
* **Решение**:
  - Обложка книги перенесена в правый верхний угол экрана (`.slide-cover-topright`, `top: 68px; right: 16px; width: 84px; height: 122px;`).
  - Добавлена эстетичная закругленная золотая рамка (`border: 1.5px solid rgba(220, 181, 94, 0.45); border-radius: 10px; box-shadow: 0 12px 30px rgba(0,0,0,0.75)`).
  - Слой с текстом цитаты находится по центру на матовой полупрозрачной подложке и больше не закрывает обложку книги.
  - Нажатие на обложку книги в углу открывает читалку `reader.html` с соответствующей книгой.

## 3. Круглая иконка конкурса «Идеяи ман калиди фардо» (`ideai_man_banner.jpg`)
* **Проблема**: Предыдущий баннер имел прямоугольную рамку со светлыми внешними углами, из-за чего в круглом элементе отображались углы карточки.
* **Решение**:
  - Сгенерирован и установлен 100% круглый официальный герб-медальон конкурса «Идеяи ман калиди фардо» на белом фоне, в точности соответствующий стилистике других республиканских конкурсов (`furugi_banner.jpg`, `ilm_banner.jpg`).
  - В центре эмблемы размещены светящийся золотой ключ-лампочка, микросхемы, шестеренки, 7 золотых звезд Таджикистана и круговая надпись с богатым золотым обрамлением.
  - В кружке `.ozmun-circle-v3` иконка отображается идеально круглой без квадратных срезов.

## 4. Конкурсы в один горизонтальный ряд с прокруткой (`index.html`)
* **Проблема**: В стилях главной страницы было жестко задано `display: grid; grid-template-columns: repeat(5, minmax(0, 1fr))`, из-за чего при добавлении 6-го конкурса он переносился на вторую строку или ломал верстку.
* **Решение**:
  - Блок `.ozmun-scroll-v3` переведен на однорядный горизонтальный скролл: `display: flex !important; flex-direction: row !important; flex-wrap: nowrap !important; overflow-x: auto !important; overflow-y: hidden !important; gap: 12px !important;`.
  - Каждый элемент `.ozmun-item-v3` зафиксирован шириной 72px (`flex: 0 0 72px`).
  - Все 6 республиканских конкурсов теперь компактно и гармонично располагаются в одну линию, которую можно удобно пролистывать влево и вправо на любых экранах смартфонов и планшетов.

## 5. Интеллектуальный помощник Soro LLM (zehn) (`ai-chat.html`)
* **Интеграция с Soro — zehn (`https://www.sorollm.tj/`)**:
  - В шапке добавлены удобные вкладки переключения:
    1. **✨ Ёвари Китобхона (AI Assistant)**: фирменный чат приложения «Китобхона» с поддержкой локальной базы знаний и гостевого API Soro.
    2. **🌐 Soro — zehn (Меҳмон)**: прямое открытие официального сервиса Soro — zehn в режиме гостя ("Ҳамчун меҳмон идома диҳед").
  - При отправке запроса чат автоматически подключается к гостевой сессии Soro LLM (`POST https://www.sorollm.tj/api/auth/guest` и `/api/chat/create`), передавая вопросы в нейросеть.
  - При отсутствии сети или лимитах сервис бесшовно переключается на встроенный таджикский интеллектуальный движок.
* **База знаний и сохранение истории**:
  - Полное сохранение истории диалогов в `localStorage` (`kk_sorollm_history_v1`) с кнопкой «🗑 Тоза кардан».
  - Подробные данные обо всех асарҳои Пешвои миллат Эмомали Рахмона («Тоҷикон дар оинаи таърих», «Забони миллат — ҳастии миллат», «Чеҳраҳои мондагор», «Нигоҳе ба таърих ва тамаддуни ориёӣ», «Истиқлолияти Тоҷикистон ва эҳёи миллат», «Аз Ориё то Сомониён»).
  - Правила использования программы: 50 часов чтения для получения верификации и разблокировки загрузки аватара, условия рейтингов ТОП-100, правила 6 республиканских конкурсов, оффлайн-библиотека.
  - **Проверка книг по каталогу**: асинхронный поиск по `books.json` — при запросе конкретной книги выдается статус ее наличия, категория и интерактивная карточка для быстрого перехода в `reader.html`.

## Инструкция по обновлению

1. **Android**: Замените `kitobkhonaapp/app/src/main/java/com/kitobkhona/app/MainActivity.kt` в вашем репозитории `sharipovip/kitobkhonaapp` и запустите сборку в GitHub Actions — теперь сборка пройдет успешно.
2. **Веб-приложение**: Замените файлы в папке `kitobkhona/` (`Lenta.html`, `index.html`, `ideai_man_banner.jpg`, `ai-chat.html` и сопутствующие файлы).
