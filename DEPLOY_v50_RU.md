## 1. Ссылки сомон — починены и почищены

Проверено реальным браузером (iframe) — найдены 3 проблемы:

| Сомона | Проблема | Решение |
|---|---|---|
| kmt.tj | стоял `http://` → на HTTPS-сайте смешанный контент, iframe блокировался | исправлено на `https://kmt.tj` |
| nlt.tj | сервер не отвечает (таймаут) | удалена из списка |
| mmk.tj | `X-Frame-Options: SAMEORIGIN` — их сервер запрещает встраивание во фрейм | открывается во внешнем браузере (метка «↗» на карточке) |

Остальные 6 сомон проверены — работают во фрейме.

## 2. Тезкушоӣ — окно показывается сразу

- Убран экран «Саҳифа кушода шуда истодааст...» — теперь при нажатии окно открывается
  сразу (~0.4 с), а сомона прогружается на глазах: браузер сам показывает её
  по мере поступления данных;
- наверху остаётся тонкая золотая полоса прогресса, которая исчезает при загрузке;
- при приближении к разделу сомон заранее устанавливаются соединения (DNS+TLS)
  со всеми 8 сомонами — открытие становится заметно быстрее.

## 3. Офлайн-режим

- Без интернета вместо пустой ошибки показывается панель: название сомоны,
  её сохранённый скриншот и кнопки «Дубора кӯшиш» / «Баромад»;
- «Дубора кӯшиш» повторяет загрузку — если сомона недавно открывалась на этом
  устройстве, браузер может показать её из своего кэша;
- скриншоты сомон всегда доступны офлайн (в кэше Service Worker).

Примечание: полностью кэшировать чужие сайты (их HTML/CSS/картинки) внутри
PWA технически невозможно — браузеры запрещают чтение междоменного содержимого.
Это ограничение всех веб-приложений, не только Китобхоны.
