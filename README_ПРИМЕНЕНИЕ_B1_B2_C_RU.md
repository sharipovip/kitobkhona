# Китобхона · Алия — этапы B1, B2, C (ветка основана на коммите 355d5af)

## Что изменено
- **B1 (Reader):** Алия на телефоне и ПК открывается на весь экран, с кнопкой «‹» назад.
- **B2 (Reader → Алия):** Алия открывается отдельной страницей с адресом `aliya/reader-aliya.html?url=…&name=…&page=…`. Есть кнопки задач и свой вопрос (логика API не менялась и не проверялась на ответах модели).
- **C (ПК-панель):** старая панель-оверлей заменена боковой панелью, которая сдвигает содержимое и сворачивается кнопкой ☰. Проверено на 1280 px и 390 px: на телефоне панели нет, отступ не меняется. Страницы /aliya/ панель пропускает.

## Файлы
- `reader.html`, `config.js`, `index.html`, `kitobho.html`, `desktop-sidebar.js`, `aliya/reader-aliya.html` — полные обновлённые файлы.
- `ALL_B1_B2_C.patch` — общий патч (`git apply`) поверх коммита 355d5af.

## Как применить
1. Скопируйте файлы в корень репозитория с заменой (сохраните структуру папок).
2. Или: `git apply ALL_B1_B2_C.patch`.
3. Обновите страницу и очистите кэш / Service Worker, иначе будет старая версия.
