# v101 — Хабарҳои Президент (prezident.tj) прямо в приложении

**Дата:** 29.09.2026 · **Тесты: 24/24 (вкл. ротацию 10 сек, фото, фолбэк), 0 JS-ошибок**

Идея пользователя реализована полностью: новости сомонаи prezident.tj показываются
**внутри приложения** — на сайт заходить не нужно. Обнаружен открытый API самого сайта
(controlpanel.president.tj, CORS разрешён) — берём заголовки, даты, полный текст и фото
(flickr) напрямую оттуда.

---

## Что сделано

### 1. Новый раздел на главной — «🇹🇯 Хабарҳои Президент»
Находится сразу под «🏆 Озмунҳои ҷумҳуриявӣ», компактный (заголовок в 1–2 строки):
- **8 категорий по горизонтали** (как в меню сайта): Хабарҳо, Вохӯриҳо, Суханрониҳо,
  Сафарҳо, Санадҳо, Паём, Барқияҳо, Суҳбатҳои телефонӣ.
- Под ними — **заголовок самой свежей новости** (дата + категория + превью-фото,
  если есть). Каждые **10 секунд** — следующая новость, по кругу из **разных
  категорий**.
- Категория текущей новости **подсвечивается** (темнее, золотая) — сразу видно,
  к чему относится заголовок.
- При каждом открытии приложения старт — со **случайной новости**.
- Тап по заголовку → полный текст новости внутри приложения.
- Тап по категории → список всех новостей этой категории.

### 2. Новая страница president.html
- Список 12 последних новостей выбранной категории (карточки: заголовок, дата,
  превью-фото).
- **Детальный вид**: заголовок, дата, **фото новости (flickr)** — тап по фото →
  просмотр на весь экран; **полный текст** внутри приложения; бейдж
  «Хабар аз сомонаи prezident.tj»; ссылка «↗ Кушодан дар сомона» (по желанию).

### 3. Архив новостей (робот, books-репо) — как просил пользователь
- `president_news.py` + workflow **каждый час**: скачивает 12 последних новостей
  каждой категории и сохраняет **каждую новость отдельным файлом**:
  `president/<категория>/<id>.json` (заголовок, дата, полный текст, фото) —
  архив только растёт.
- `president/index.json` — резервный список: если API сайта временно недоступен,
  приложение показывает новости **из архива** (проверено тестом).
- Коммит создаётся только когда появились новые новости (репо не засоряется).
- Первый запуск: ~97 файлов (~3 МБ).

## Установка

### Веб (работает сразу, даже без робота)
1. Распакуйте `kitobkhona_v101_patch.zip` поверх веб-репо
   (4 файла + эта инструкция).
2. Закоммитьте → GitHub Pages.
3. На телефоне полностью закройте и откройте приложение.

### Робот-архив (books-репо)
1. Распакуйте `books_v101_president_patch.zip` в корень books-репо
   (2 файла: `president_news.py` и `.github/workflows/president-news.yml`).
2. Закоммитьте.
3. GitHub → Actions → **«🇹🇯 President news archive»** → Run workflow (первый
   запуск можно вручную, дальше — сам каждый час). Первый запуск ~3–4 минуты.

Порядок не важен: раздел на главной работает сразу через API сайта,
робот лишь добавляет архив и резервную копию.
