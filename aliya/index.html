Маълумот дар ин дастгоҳ

Чатҳо, лоиҳаҳо, ёддоштҳо ва таърихи овоз байни дастгоҳҳо ҳамоҳанг намешаванд.

Нусхаи JSON метавонад матни чатҳо ва профили шахсии сабтшударо дар бар гирад; файлро эҳтиёткорона нигоҳ доред. Барқароркунӣ аз JSON дар ин версия нест. Файлҳои аслии ҳуҷҷат ва аксҳо дар чат сабт намешаванд.
Забони ҷавобро худи саволи шумо муайян мекунад. Интерфейси вебии ҳозир тоҷикӣ аст; тарҷумаи пурраи UI, тақсимоти хотираи телефон ва бастаи овоз/моделҳои APK ба ин версия интиқол дода нашудаанд.
